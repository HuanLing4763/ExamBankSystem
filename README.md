# 题库管理系统

## 一、项目概述
ExamBankSystem 是一个基于 Qt 框架开发的题库管理系统，旨在为用户提供专项练习、模拟考试等功能，同时支持多考试环境的管理与切换。系统通过与 VirtualBox 集成，实现虚拟考试环境的启动与控制，为用户提供更加真实的考试体验。

## 二、功能特性
1. **多页面导航**：包含专项练习、模拟考试和考试环境管理三个核心功能页面，通过侧边栏按钮轻松切换。
2. **自定义窗口控制**：支持自定义标题栏拖拽、窗口最小化、最大化、还原和关闭操作。
3. **侧边栏动画效果**：侧边栏按钮悬停时展开，离开时收起，增强用户交互体验。
4. **虚拟考试环境**：可选择不同的考试环境，将考试参数写入共享文件夹，并启动对应的虚拟机进行考试。
5. **加载界面**：在虚拟机启动过程中显示加载界面，提供良好的用户反馈。
6. **文件系统监控**：监控共享文件夹的变化，当检测到虚拟机关闭信号时，自动启动宿主机应用程序。

## 三、项目结构
```
ExamBankSystem/
├── CMakeLists.txt            # CMake 配置文件
├── CMakePresets.json         # CMake 预设配置
├── CMakeUserPresets.json     # 用户自定义 CMake 预设
├── config.ini                # 服务器配置文件
├── ExamBankSystem.qrc        # 资源文件
├── LICENSE.txt               # 项目许可证
├── qml/                      # QML 文件目录
│   └── Loading.qml           # 加载界面 QML 文件
├── resources                 # 资源文件目录
├── sdk/                      # VirtualBox SDK 目录
└── src/                      # 源代码目录
    ├── core/                 # 核心功能模块
    │   ├── env/              # 考试环境管理模块
    │   └── virtualbox/       # VirtualBox 控制模块
    ├── gui/                  # 图形用户界面模块
    │   ├── exam/             # 模拟考试页面
    │   ├── examEnv/          # 考试环境管理页面
    │   ├── main/             # 主窗口页面
    │   └── special/          # 专项练习页面
    └── main.cpp              # 程序入口文件
```

## 四、环境要求
1. **操作系统**：Windows、Linux
2. **开发工具**：CMake 3.16 及以上、Qt 5 或 Qt 6
3. **依赖库**：VirtualBox SDK

## 五、编译与运行
### 1. 配置 CMake
确保已经安装了 CMake 和 Qt 开发环境，并设置好 `QTDIR` 环境变量。
```bash
cmake -S . -B build
```

### 2. 编译项目
```bash
cmake --build build
```

### 3. 运行程序
```bash
./build/ExamBankSystem
```

## 六、使用说明
1. **启动程序**：运行编译生成的可执行文件 `ExamBankSystem`。
2. **页面导航**：通过侧边栏按钮切换专项练习、模拟考试和考试环境管理页面。
3. **专项练习**：在专项练习页面选择题目类型进行练习。
4. **模拟考试**：在模拟考试页面点击“进入考试”按钮，系统将自动选择当前考试环境，将考试参数写入共享文件夹，并启动对应的虚拟机进行考试。
5. **考试环境管理**：在考试环境管理页面可以查看当前考试环境，并进行环境切换操作。

## 七、注意事项
1. 确保 VirtualBox 已经正确安装，并且配置了相应的虚拟机。
2. 检查 `config.ini` 文件中的服务器配置信息是否正确。
3. 资源文件路径为硬编码，需确保 `ExamBankSystem.qrc` 中包含了所有必要的图片资源。
